勝ち負けを分けるのは、エントリー後の判断。

エントリーはできても、利確・損切り・建値移動・ロット管理で崩れる。 EXIT NAVIは、まさにその「出口判断」を補助するために設計しています。

参考SLを自動表示

エントリー後、TP方向に対してどこを割る・抜けるとシナリオが崩れやすいかを参考SLとして表示します。

BUY時は下側、SELL時は上側に、構造が否定されやすい価格帯を視覚的に整理できます。
Reference SL
ポジション保有後に、シナリオ崩れの目安となる参考SLを自動表示。感覚ではなく、出口判断の基準として使いやすい見せ方です。

TP1 / TP2 / TP3

TP1は近い利確候補、TP2は根拠が重なりやすい本命候補、TP3は伸長候補として表示します。

TP2を中心に、フィボナッチ・ATR・水平線などの根拠が重なる価格を基準化。TP1とTP3はその前後の取りやすい候補として整理します。
TP1 / TP2 / TP3
利確候補を1本ではなく複数段階で表示。短期決済・標準決済・伸長候補を見比べながら、裁量に合わせた出口設計ができます。

決済後レビュー

最終結果、最大到達、最大逆行、参考SL距離をpipsで振り返り、次のトレード改善につなげます。

レビューは金額ではなくエントリー位置基準のpipsで確認。ブローカー差やロット差に左右されにくく、振り返りしやすい形式です。
Trade Review
最終結果 / 最大到達 / 最大逆行 / 参考SL距離をレビュー表示。トレード後の改善材料を、その場で確認できます。

3つのトレードスタイルに対応

ユーザーが触る項目は必要最小限。Scalping / Day / Swingを切り替えるだけで使えます。

Style 想定 使い方
Scalping 短期売買。秒〜分単位の値動きも想定。 TP1で素早く逃げる、TP2で標準利確、TP3で伸長確認。
Day 標準設定。迷ったらまずDay。 日中の値動きに対して、バランスよく出口を管理。
Swing H1基準の短中期スイング。 構造的な否定位置をSLに、TP2を本命利確候補として確認。

使い方はシンプル

複雑な設定を覚える必要はありません。ポジション保有後、パネルを見るだけで出口判断の材料を整理できます。

WHY EXIT NAVI

エントリー後に崩れるトレードを、出口から整える。

多くのトレードは、エントリーよりも「利確を早めすぎた」「損切りを遅らせた」「ロットを重くしすぎた」 という出口判断で崩れます。EXIT NAVIは、保有中の判断材料をチャート上に集約し、裁量トレーダーの迷いを減らすための出口管理パネルです。

利確判断を段階化

TP1・TP2・TP3で、短期利確、本命利確、伸長候補を分けて確認できます。

損切り判断を明確化

参考SLを表示することで、どこを超えたらシナリオが崩れやすいかを確認できます。

ロット圧力を確認

ポジションが重くなりすぎていないかを、保有中に見直しやすくなります。

決済後に改善

最終結果、最大到達、最大逆行をpipsで振り返り、次回の出口判断に活かせます。

画像を差し替える場合

GitHubに画像を入れて使う場合は、HTML内の画像パスに合わせて assets フォルダへアップロードしてください。

使用する画像ファイル名

2. assets/exit-navi-tp.jpg：TP1 / TP2 / TP3の画像
3. assets/exit-navi-review.jpg：決済後レビューの画像

推奨サイズは横長 1600×900px または 1280×720px、形式は JPG がおすすめです。
